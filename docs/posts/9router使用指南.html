项目概述

9Router 是一个开源的免费 AI 路由器和 Token 节省器，可以将你的 AI 编程工具（Claude Code、Cursor、Codex 等）连接到 40+ AI 提供商和 100+ 模型。

核心价值

  • RTK Token 节省器：每次请求节省 20-40% tokens
  • 智能三层切换：订阅 → 低价 → 免费，永不停机
  • 格式自动转换：OpenAI ↔︎ Claude ↔︎ Gemini 等格式无缝兼容
  • 完全免费开源：9Router 本身从不收费

工作原理

┌─────────────┐
│  你的 CLI   │  (Claude Code、Codex、OpenClaw、Cursor、Cline...)
│   工具      │
└──────┬──────┘
       │ http://localhost:20128/v1
       ↓
┌─────────────────────────────────────────────┐
│           9Router（智能路由器）              │
│  • RTK Token 节省器（减少 tool_result tokens）│
│  • 格式转换（OpenAI ↔ Claude）              │
│  • 配额追踪                                  │
│  • 自动刷新 token                           │
└──────┬──────────────────────────────────────┘
       │
       ├─→ [第一层：订阅] Claude Code、Codex、GitHub Copilot
       │   ↓ 配额耗尽
       ├─→ [第二层：低价] GLM ($0.6/1M)、MiniMax ($0.2/1M)
       │   ↓ 预算超限
       └─→ [第三层：免费] Kiro、OpenCode Free、Vertex ($300 额度)

结果：编程永不停歇，最小成本 + 通过 RTK 节省 20-40% tokens

安装与启动

方法 1：npm 全局安装（推荐）

npm install -g 9router
9router

Dashboard 默认在 http://localhost:20128 打开。

方法 2：从源码运行

# 克隆仓库
git clone https://github.com/decolua/9router.git
cd 9router

# 配置环境变量
cp .env.example .env
npm install

# 开发模式
PORT=20128 NEXT_PUBLIC_BASE_URL=http://localhost:20128 npm run dev

# 生产模式
npm run build
PORT=20128 HOSTNAME=0.0.0.0 NEXT_PUBLIC_BASE_URL=http://localhost:20128 npm run start

默认 URL： - Dashboard：http://localhost:20128/dashboard - OpenAI 兼容 API：http://localhost:20128/v1

方法 3：Docker

使用发布镜像（推荐）：

docker run -d \
  --name 9router \
  -p 20128:20128 \
  -v "$HOME/.9router:/app/data" \
  -e DATA_DIR=/app/data \
  decolua/9router:latest

从源码构建：

git clone https://github.com/decolua/9router.git
cd 9router
docker build -t 9router .
docker run -d --name 9router -p 20128:20128 \
  -v "$HOME/.9router:/app/data" -e DATA_DIR=/app/data 9router

常用 Docker 命令：

docker logs -f 9router          # 查看日志
docker restart 9router          # 重启
docker stop 9router && docker rm 9router  # 停止并删除
docker pull decolua/9router:latest  # 更新到最新版

核心功能详解

🚀 RTK Token 节省器

工具输出（git diff、grep、find、ls、tree、日志转储…）通常占用 30-50% 的提示词预算。RTK 在请求到达 LLM 之前检测并应用智能、无损压缩：

支持的过滤器：git-diff、git-status、grep、find、ls、tree、dedup-log、smart-truncate、read-numbered、search-list

特点： - 自动检测：无需配置，RTK 检查每个 tool_result 的前 1KB，选择合适的过滤器 - 安全设计：如果过滤器失败或使输出变大，RTK 静默保留原始文本 - 默认开启：可在 Dashboard → Endpoint 设置中切换

不使用 RTK：47K tokens 发送给 LLM
使用 RTK：    28K tokens 发送给 LLM   (节省 40% · 相同上下文 · 相同答案)

🪨 Caveman 模式

注入 caveman 风格提示词 → LLM 回复简洁，保留技术实质，节省高达 65% 输出 tokens。

🎯 智能三层切换

创建具有自动切换功能的 Combo：

Combo: "my-coding-stack"
  1. cc/claude-opus-4-6        （你的订阅）
  2. glm/glm-4.7               （低价备份，$0.6/1M）

→ 配额用完或出错时自动切换

OpenClaw

方法 1 — Dashboard（推荐）：

Dashboard → CLI Tools → OpenClaw → 选择模型 → 应用

方法 2 — 手动：编辑 ~/.openclaw/openclaw.json：

{
  "agents": {
    "defaults": {
      "model": {
        "primary": "9router/kr/claude-sonnet-4.5"
      }
    }
  },
  "models": {
    "providers": {
      "9router": {
        "baseUrl": "http://127.0.0.1:20128/v1",
        "apiKey": "sk_9router",
        "api": "openai-completions",
        "models": [
          {
            "id": "kr/claude-sonnet-4.5",
            "name": "Claude Sonnet 4.5 (Kiro Free)"
          }
        ]
      }
    }
  }
}

⚠️ 注意：OpenClaw 必须使用 127.0.0.1 而非 localhost，以避免 IPv6 解析问题。

环境变量配置

变量 默认值 说明
JWT_SECRET 自动生成（~/.9router/jwt-secret） JWT 签名密钥（可覆盖以跨实例共享）
INITIAL_PASSWORD 123456 首次登录密码（无保存哈希时使用）
DATA_DIR ~/.9router 主应用数据位置（SQLite 在 $DATA_DIR/db/data.sqlite）
PORT 框架默认值 服务端口（示例中为 20128）
HOSTNAME 框架默认值 绑定主机（Docker 默认为 0.0.0.0）
NODE_ENV 运行时默认 设为 production 用于部署
BASE_URL http://localhost:20128 服务端内部基础 URL（云同步使用）
CLOUD_URL https://9router.com 服务端云同步端点基础 URL
NEXT_PUBLIC_BASE_URL http://localhost:3000 向后兼容/公开基础 URL
NEXT_PUBLIC_CLOUD_URL https://9router.com 向后兼容/公开云 URL
API_KEY_SECRET endpoint-proxy-api-key-secret 生成 API key 的 HMAC 密钥
MACHINE_ID_SALT endpoint-proxy-salt 稳定机器 ID 哈希的盐值
ENABLE_REQUEST_LOGS false 在 logs/ 下启用请求/响应日志
AUTH_COOKIE_SECURE false 强制 Secure auth cookie（HTTPS 反向代理后设为 true）
REQUIRE_API_KEY false 在 /v1/* 路由强制 Bearer API key（互联网部署推荐）
HTTP_PROXY / HTTPS_PROXY / ALL_PROXY / NO_PROXY 空 可选出站代理（也支持小写形式）

常见问题与解决方案

Q: 为什么 Dashboard 显示高成本？

Dashboard 显示的”成本”是估算成本，表示如果你直接使用付费 API 需要支付的金额。这不是实际账单，而是节省追踪器。

示例： - Dashboard 显示：“$290 总成本” - 实际情况：你在使用免费提供商（如 Kiro） - 你的实际支付：$0 - $290 的含义：你通过使用免费模型节省的金额

Q: 9Router 会扣我的钱吗？

不会。 9Router 是在你自己的电脑上运行的开源软件，从不收费。

你只需支付： - ✅ 订阅提供商（Claude Code、Codex）→ 在他们的网站上直接付款 - ✅ 低价提供商（GLM、MiniMax）→ 直接付款，9Router 只做路由 - ❌ 9Router 本身 → 永不收费

Q: 免费提供商真的是无限量的吗？

是的。 当前的免费提供商（Kiro、OpenCode Free、Vertex）是真正的免费，无隐藏费用：

  • Kiro AI：通过 AWS Builder ID / Google / GitHub OAuth，免费无限量使用 Claude 4.5 + GLM-5 + MiniMax
  • OpenCode Free：无认证直连代理，模型自动获取
  • Vertex AI：新 Google Cloud 账户可获得 $300 免费额度（90天）

Q: “语言模型未提供消息” 错误

原因：提供商配额耗尽

解决方案： 1. 检查 Dashboard 配额追踪器 2. 使用 Combo 切换到其他提供商 3. 切换到更便宜的等级

Q: 速率限制问题

解决方案：添加 Combo 切换

cc/claude-opus-4-7 → glm/glm-5.1 → kr/claude-sonnet-4.5

Q: OAuth token 过期

  • 9Router 会自动刷新
  • 如问题持续：Dashboard → Provider → 重新连接

Q: 首次登录不工作

  1. 检查 .env 中的 INITIAL_PASSWORD
  2. 默认回退密码：123456

Q: logs/ 下没有请求日志

设置 ENABLE_REQUEST_LOGS=true

Q: 控制面板在错误端口打开

设置 PORT=20128 和 NEXT_PUBLIC_BASE_URL=http://localhost:20128

重要注意事项

1. 免费提供商状态（2026年）

提供商 状态 说明
✅ Kiro AI 免费无限 推荐使用
✅ OpenCode Free 免费无需认证 推荐使用
✅ Vertex AI $300 免费额度 新 GCP 账户可用
❌ iFlow 已停止免费 2026年改为付费
❌ Qwen Code 已停止免费 2026-04-15 停止
⚠️ Gemini CLI 有风险 与非 CLI 工具混用可能导致账户被封

2. RTK Token 节省器

  • 默认开启，可在 Dashboard → Endpoint 设置中关闭
  • 建议保持开启以节省 20-40% tokens
  • 压缩过程无损，不影响输出质量

3. 数据存储

  • 主数据库：${DATA_DIR}/db/data.sqlite
  • 自动备份：${DATA_DIR}/db/backups/
  • 请求日志：<repo>/logs/...（需启用 ENABLE_REQUEST_LOGS）

4. 安全建议

  • 互联网部署：设置 REQUIRE_API_KEY=true
  • HTTPS 反向代理：设置 AUTH_COOKIE_SECURE=true
  • 修改默认密码：更改 INITIAL_PASSWORD
  • 保护 JWT 密钥：设置安全的 JWT_SECRET

5. 成本显示

Dashboard 显示的”成本”仅供参考： - 表示直接使用付费 API 需要支付的金额 - 不是实际账单 - 用于追踪和比较节省金额
