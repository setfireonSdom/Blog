Graphify 入門指南

把你的程式碼庫變成可查詢的知識圖譜 — 讓 AI 助手真正「看懂」你的專案。

這是什麼？

Graphify 是一個 CLI 工具，掃描你的程式碼庫（程式碼、文件、PDF、圖片、影片），自動構建一份知識圖譜。之後你可以直接對圖譜提問，不用手動翻檔案。

一句話本質： 與其讓 AI 每次從零 grep 你的程式碼庫，不如先建一份地圖，以後所有問題都對著地圖問。

它解決什麼問題？

痛點 以前 有 Graphify
接手陌生專案 到處翻檔案，不知道從哪看起 graph.html 視覺化展示核心概念和子系統
跨檔案追蹤關聯 手動 grep + 拼湊上下文，容易漏 graphify path A B 直接告訴你連線路徑
context window 不夠 AI 只能看到你餵的片段，看不到全局 整個程式碼庫濃縮成 graph.json，token 節省 71x
團隊知識傳承 靠口頭或文件，總是過期 graphify-out/ 進 git，新人 clone 就有地圖

快速入門（30 秒）

1. 安裝

# 推薦（隔離環境）
uv tool install graphifyy

# 或
pipx install graphifyy

PyPI 包名是 graphifyy（兩個 y），CLI 指令仍是 graphify。

2. 註冊到你的 AI 助手

graphify install

支援的平台：Claude Code、Cursor、Codex、Gemini CLI、OpenCode、GitHub Copilot 等 20+。

3. 建圖

在專案目錄下，於 AI 助手中輸入：

/graphify .

或直接 CLI 執行：

graphify extract .

4. 拿到什麼

graphify-out/
├── graph.html       在瀏覽器打開 — 可點擊、篩選、搜尋
├── GRAPH_REPORT.md  重點摘要：God nodes、驚喜連線、建議提問
└── graph.json       完整圖譜 — 之後隨時查詢，不用重掃

查詢範例

# 查 auth 與資料庫的關係
graphify query "auth 和資料庫之間有什麼連接？"

# 追蹤兩個概念之間的最短路徑
graphify path "UserService" "DatabasePool"

# 解釋某個概念
graphify explain "RateLimiter"

# 拉論文進圖譜
graphify add https://arxiv.org/abs/1706.03762

支援什麼檔案

類型 格式 解析方式
程式碼 .py .ts .js .go .rs .java .cpp .rb .cs .kt .php .swift .vue .svelte 等 36+ 語言 tree-sitter AST（完全本地，0 API 調用）
文件 .md .mdx .txt .rst .html .yaml LLM 語義提取（可選本地 Ollama）
PDF .pdf LLM 語義提取
圖片 .png .jpg .webp .gif LLM Vision
影片/音檔 .mp4 .mov .mp3 .wav faster-whisper 本地轉文字
Office .docx .xlsx 需安裝 [office] 擴展

團隊協作

# 提交圖譜到 git
git add graphify-out/

# 安裝 git hook，每次 commit 自動重建圖譜
graphify hook install

graphify-out/ 提交到 git 後，團隊所有人 clone 即有地圖。合併衝突時會自動 union-merge，不會留下衝突標記。

核心概念

  • Graph：整個知識圖譜，存在 graph.json
  • Node（節點）：檔案中的一個概念（類別、函數、變數、文件段落等）
  • Edge（邊）：節點之間的關係，標記為 EXTRACTED（來源明確引用）或 INFERRED（推理得出）
  • Community（社群）：Leiden 演算法自動聚類出的子系統
  • God node：圖中度數最高的節點（連接最多東西的 core concept）

技術原理

程式碼檔案 ──→ tree-sitter AST 解析 ──→ 提取節點+邊（calls/imports/inherits）
                                              │
文件/PDF/圖片 ──→ LLM 語義提取 ───────────────┘
                                              │
                                              ↓
                                     NetworkX 圖結構
                                              │
                                              ↓
                              ┌── graph.html（vis.js 視覺化）
                              ├── GRAPH_REPORT.md
                              └── graph.json（供查詢遍歷）
  • 程式碼解析：tree-sitter，確定性、無成本、全本地
  • 社群檢測：Leiden 演算法（graspologic）
  • 圖儲存：NetworkX
  • 查詢方式：圖遍歷（不是 vector search，沒有 embedding）

隱私

  • 程式碼檔案：完全本地，永不離開你的機器。Code-only 專案甚至不需要 API Key
  • 影片/音檔：本地轉文字（faster-whisper）
  • 文件/PDF/圖片：可選後端（Ollama 全本地 / Claude / OpenAI / Gemini / DeepSeek）
  • 無遙測、無使用追蹤、無分析

與其他方案對比

Graphify 向量資料庫（RAG）
儲存方式 圖結構（節點+邊） 向量 embedding
解析方式 AST + LLM 語義 chunk + embedding
查詢方式 圖遍歷 相似度搜尋
跨檔案關聯 原生支援（明確邊） 需要額外處理
結果可溯源 每個邊有 EXTRACTED/INFERRED 標籤 黑盒子
LLM 成本（Code only） 0 每次都要
