全球大模型家族调研

调研快照：2026-09-02

本文统计的是“模型家族”，不是模型版本。比如 Qwen 2、Qwen 3、Qwen-VL、Qwen-Coder、QwQ 均归入 Qwen；不同参数规模、量化版、Base/Instruct/Chat 版也不重复计数。

一、先看结论

在本次公开资料核验范围内，共整理出 126 个独立模型家族：

分类 数量 含义
闭源/专有（C） 18 权重未公开，主要通过 API、云服务、产品或企业部署提供
混合开放（M） 19 同一家族同时存在闭源服务和公开权重，或公开程度随子系列变化
开放权重/源码（O） 44 至少有公开权重或代码；许可证可能是 Apache、MIT、定制条款等
研究发布/受限（R） 45 有公开检查点、论文或研究项目，但存在非商用、区域、申请、旧项目或许可证限制
合计 126 按家族去重，不按版本计数

这里的“开源”需要谨慎理解：很多模型只是 open weights（开放权重），并没有开放训练数据、完整训练代码或完全自由的商业许可。真正能否商用，应以具体检查点的模型卡和许可证为准。

二、统计口径

纳入

  • 由公司、研究机构、大学、政府项目或联合组织正式训练、发布或运营的通用文本生成模型。
  • 具有通用语言、推理、代码生成或多模态语言生成能力的模型家族。
  • 有官网、官方仓库、官方模型卡、论文或官方文档等一手证据。
  • 仍在运营的家族和有明确公开证据的历史/研究家族都保留，但会标注状态。
  • 地区语言模型、企业专用基础模型和多模态语言模型可以纳入，只要其核心仍是语言生成模型。

不纳入或不重复

  • ChatGPT、Claude、Gemini、Kimi、豆包等应用名不单独算模型；统计其背后的模型家族。
  • 同一模型的版本、日期快照、参数规模、量化版、Base/Instruct/Chat 版不重复计算。
  • LLaMA 衍生微调、单纯 RAG、模型聚合平台和 API 转售平台不作为新的基础家族。
  • 纯图片、视频、语音识别、向量 embedding、排序器和 moderation 模型不纳入主表。
  • 同一公司的不同基础家族仍分别统计，例如 Google 的 Gemini 和 Gemma、Cohere 的 Command 和 Aya、Amazon 的 Nova 和 Titan。

状态代码

  • C：闭源/专有：没有公开可下载的模型权重。
  • M：混合开放：API/商业服务与公开权重并存，或同一品牌下开放性差异很大。
  • O：开放权重/源码：至少有可下载权重或较完整的公开代码；不代表许可证一定宽松。
  • R：研究发布/受限：公开了权重、论文或检查点，但受非商用、申请、区域、定制许可证、基于其他模型或项目已不活跃等限制。

四、开放性和谱系的关键判断

1. “开源”至少要拆成三层

层级 判断标准 典型情况
开放权重 可以下载或申请下载权重 Llama、Qwen、DeepSeek、Mistral、Falcon、Phi 等，但很多使用定制许可
开放代码/训练配方 代码、配置、训练方法也公开 OLMo、Pythia、部分 BigScience 项目更接近这一层
开放数据与可复现研究 数据、训练过程、权重、代码和论文尽量完整公开 研究透明度较高，但仍不自动等于无限制商用

因此，本文把 O 和 R 分开：O 代表比较明确的开放权重/源码；R 代表公开但限制明显、偏研究、依赖底座、检查点较旧或许可证不完整的项目。

2. 同一公司可以同时拥有闭源和开放模型

  • Google：Gemini 是闭源产品线，Gemma 是公开权重线。
  • Meta：Llama 是公开权重但使用定制许可，不能简单写成“完全开源”。
  • Cohere：Command 同时有商业服务和公开权重，Aya 是研究/多语言公开线。
  • AI21：Jurassic 以商业服务为主，Jamba 有公开权重和 API 线。
  • 字节跳动：Doubao 是商业模型产品，Seed 是研究和开放发布线。
  • 腾讯：混元既有企业/API 产品，也有部分公开权重。
  • 智谱：GLM 既有 API，也有公开权重版本。
  • Kakao：Kanana 同时覆盖商业 AI 产品和公开的 Kanana-2 模型线。

3. 地区模型不一定是“从零训练”

SEA-LION、Typhoon、Sahabat-AI、Latam-GPT、ELYZA、Swallow、Ziya 等项目可能建立在 Llama、Qwen、Gemma 或其他开放底座之上，再进行继续预训练、领域训练或对齐。它们仍可作为独立的地区模型项目统计，但不能把它们和完全自研基础模型混为一谈。

六、没有纳入主表的名称

下列类别不是遗漏，而是按口径排除：

  • Sora、Veo、Stable Diffusion、Kling 等纯视频/图像生成模型。
  • Whisper、Voxtral Transcribe 等以语音识别为主的模型。
  • text-embedding、reranker、moderation、OCR-only 模型。
  • OpenRouter、Replicate、Together Inference、Groq 等模型托管或聚合服务。
  • 只有产品宣传、没有可核验模型证据的“国家大模型”或尚未公开的内部项目。
  • 仅在新闻中出现、没有公开模型卡、论文或官方文档支撑的型号。

七、使用这份清单时的注意事项

  1. 不要把“能在线调用”理解成“模型开放”。 API 可调用只说明服务开放，不说明权重开放。
  2. 不要只看 GitHub 代码许可证。 模型代码、权重、训练数据和输出使用条款可能完全不同。
  3. 商用前必须查看具体模型卡。 同一模型家族中，不同版本的许可证、地域和用户规模限制可能不同。
  4. 闭源模型的参数量、训练数据和架构常常不公开。 文档没有强行补齐这些信息，避免把媒体推测写成事实。
  5. 模型家族变化很快。 本文是 2026-09-02 的公开资料快照，后续可能出现新家族、改名、停服或许可证变更。

八、资料优先级

本次核验按以下优先级使用来源：

  1. 出品方官网、API 文档和模型目录。
  2. 出品方 GitHub 组织、官方模型仓库和官方模型卡。
  3. 出品方论文、技术报告和正式公告。
  4. Hugging Face 官方组织/模型卡，用于权重、许可证和谱系交叉核对。
  5. 新闻、榜单和第三方目录只用于发现候选，不作为关键事实的唯一证据。

结论

如果只想记住商业上最重要的一层，核心闭源家族包括 GPT、Claude、Gemini、Grok、Nova、Titan、Jurassic、Palmyra、Reka、Pi，以及中国和区域市场的 Doubao、Spark、SenseNova、GigaChat、YandexGPT、tsuzumi 等。Command、Kanana、Sabiá 等应视为混合开放家族，而不是纯闭源家族。

如果重点是自部署和开放生态，核心公开家族包括 Llama、Qwen、DeepSeek、Mistral、Gemma、Phi、OLMo、OpenELM、Cerebras-GPT、Granite、Nemotron、Falcon、Jais、LLM-jp、InternLM、MiniCPM、Step、LongCat、Ling、MiMo、Apertus、EuroLLM、Bielik、Poro、Viking 等，但仍应逐个核对具体许可证，而不是只依据“开源”标签做商业判断。
