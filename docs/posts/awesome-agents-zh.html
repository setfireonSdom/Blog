  • SwarmClaw：自托管的 AI 运行时，用于多 Agent 编排，支持心跳、调度、委托、记忆和运行时技能，覆盖 OpenClaw、Claude Code、Codex、Gemini CLI 和主流 LLM 提供商。以桌面应用（Electron）和 CLI 形式发布
  • smolagents：开源 Python 库，让你只需几行代码就能极简地构建和运行 Agent
  • open-multi-agent：TypeScript 多 Agent 框架。一次 runTeam() 调用，用一次 LLM 调用将目标分解为任务 DAG 并并行执行。仅三个运行时依赖，Node.js 18+
  • Aeon：通过 GitHub Actions 无人值守运行的自主 Agent 框架，具备自愈技能、输出质量评分、持久记忆和响应式触发器。90+ 内置技能（研究、开发、加密、生产力、社交），MCP + A2A 集成，fork 即用模式
  • Cordum：自主 AI Agent 的进程外治理控制平面——调度前策略执行、审批关卡和签名审计跟踪，适用于生产治理
  • trpc-agent-go：用于构建生产级 Agent 系统的 Go 框架，支持图谱工作流、工具、记忆、A2A、AG-UI、MCP、评估和可观测性
