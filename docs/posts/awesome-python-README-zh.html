AI 与智能体

构建 AI 应用、集成 LLM 以及开发自主智能体的库。

  • 智能体技能
    • django-ai-plugins - 为 Django、DRF、Celery 和 Django 特定代码审查提供的 Django 后端智能体技能。
    • graphify - 将任意代码、SQL 模式、文档、论文、图片或视频文件夹转化为可查询的知识图谱。
    • nuwa-skill - 女娲蒸馏任何人的思想——让马斯克、Naval、芒格和费曼为你工作。
    • sentry-skills - 面向 Python 的工程技能，用于代码审查、调试和后端工作流。
    • trailofbits-skills - 面向 Python 的安全技能，用于审计、测试和更安全的后端开发。
  • 编排
    • ag2 - 一个开源智能体操作系统（AgentOS），用于多智能体编排和构建智能体 AI 系统。
    • autogen - 一个用于构建智能体 AI 应用的编程框架。
    • bernstein - 一个确定性 Python 编排器，用于 CLI 编码智能体（Claude Code、Codex、Gemini CLI 等 40 多个），支持并行 git worktrees 和 HMAC 签名审计链。
    • bindu - 一个框架，可为任何智能体处理器包装基于 DID 的加密身份、A2A JSON-RPC over HTTP、OAuth2 认证、x402（USDC）支付以及内置的操作员收件箱。
    • bub - 一个轻量级、hook 优先的 Python 框架，用于构建与人类共存的渠道原生智能体。
    • crewai - 一个用于编排角色扮演自主 AI 智能体的框架，以协作解决问题。
    • dspy - 一个用于编程（而非提示）语言模型的框架。
    • hermes-agent - 一个与你一同成长的适应性 AI 智能体框架。
    • langchain - 通过可组合性构建基于 LLM 的应用。
    • langgraph - 底层编排框架，用于构建有状态、长时间运行的 LLM 智能体。
    • openai-agents - OpenAI 用于构建和管理 AI 智能体的框架。
    • OpenChronicle - 开源、本地优先的记忆系统，适用于任何支持工具的 LLM 智能体。
    • promptise - 一个用于构建端到端生产级智能体系统的框架，支持可扩展、安全的 MCP 和自主智能体。
    • pydantic-ai - 一个 Python 智能体框架，用于构建具有结构化模式的生成式 AI 应用。
    • TradingAgents - 一个多智能体 LLM 金融交易框架。
  • 数据层
    • entroly - 一个可审计的上下文控制平面，可优化提示上下文、稳定缓存前缀，并通过 WITNESS 在本地验证答案。
    • instructor - 一个从 LLM 提取结构化数据的库，基于 Pydantic 构建。
    • llama-index - 一个为你的 LLM 应用提供的数据框架。
    • mem0 - 一个面向 AI 智能体的智能记忆层，支持个性化交互。
    • outlines - 为 LLM 提供结构化文本生成，支持 JSON Schema、正则表达式和语法约束解码。
  • 预训练模型与推理
    • diffusers - 一个提供预训练扩散模型的库，用于生成和编辑图像、音频和视频。
    • LiteLLM - 使用 OpenAI 格式调用 100 多个 LLM。
    • liter-llm - 一个通用 LLM API 客户端，基于 Rust 内核，通过统一的 OpenAI 兼容接口调用 142 个以上的提供商，内置代理和 MCP 服务器。
    • mlx-lm - 在 Apple Silicon 上使用 MLX 运行和微调大语言模型。
    • sglang - 一个高性能大语言模型和多模态模型的服务框架。
    • transformers - 一个让你轻松使用预训练 transformer 模型进行 NLP、视觉和音频任务的框架。
    • unsloth - 一个用于更快 LLM 微调和训练的库，内存占用更低。
    • vllm - 一个高吞吐量、内存高效的 LLM 推理和服务引擎。
  • 语音
    • funasr - 工业级语音识别工具包，支持 170 倍实时速度、50 多种语言、说话人分离和情感检测。
    • openai-whisper - 一个通用自动语音识别模型，在 68 万小时的多语言多任务监督数据上训练而成。
    • SenseVoice - 一个多语言语音理解模型，支持语音识别、语种识别、情感识别和音频事件检测。
    • vibevoice - 微软推出的开源语音 AI 模型系列，用于文本转语音和长语音识别。
    • voxcpm - 一个无分词器的文本转语音基础模型，用于多语言语音生成和声音克隆。

  • pytorch - 支持强大 GPU 加速的张量和动态神经网络框架。

  • stable-baselines3 - Stable Baselines（深度）强化学习算法的 PyTorch 实现。
  • tensorflow - Google 创建的最流行的深度学习框架。

  • xgboost - 一个可扩展、可移植、分布式的梯度提升库。
